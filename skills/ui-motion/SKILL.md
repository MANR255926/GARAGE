# Motion Philosophy

- Use subtle motion, never distracting motion
- Prefer opacity + translate over scale explosions
- Use stagger delays between 0.03â€“0.08s
- Use spring animations for UI elements
- Hover animations should complete under 200ms
- Prefer easing: easeOut
- Layout transitions should feel physical
- Animate hierarchy, not everything equally
- Respect reduced-motion accessibility
